## `raw/pmdata/p01_wellness.csv` … `p16_wellness.csv`
Third-party PMData wellness files used by `scripts/wellness_validation.py`. Per-file hashes are written into `derived/wellness_results.json`.

License note: the current Simula dataset portal displays a Creative Commons attribution license, while the original 2020 PMData paper states **CC BY-NC 4.0** for research/teaching use. ATHENA therefore treats the PMData raw files conservatively under the more restrictive **CC BY-NC 4.0** interpretation unless the dataset owner clarifies otherwise. The deployment package excludes these raw files entirely.

## `derived/research_results.json`
Generated by `scripts/research_pipeline.py`. Canonical primary-performance artifact loaded by Research Studio.

## `derived/wellness_results.json`
Generated by `scripts/wellness_validation.py`. Canonical secondary-wellness artifact loaded by Research Studio.

## `derived/research_results_v0_failed.json`
Preserved development artifact documenting an earlier primary model that underperformed the personalized baseline.

## Rebuild

```bash
npm run research
```
