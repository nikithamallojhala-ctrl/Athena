## What makes it different

- Supports sprints, hurdles, distance, jumps, throws, relays, and multi-event athletes.
- Evaluates all 24 possible four-athlete relay orders.
- Creates event-specific, explainable daily readiness insights.
- Pressure-tests a planned workout against wellness, event demands, duration, intensity, and heat.
- Builds an SBAR-style athlete-to-nurse or athlete-to-trainer communication note.
- Includes an athlete research studio with CSV export.
- Stores data in the browser only and works offline after the first load.

## Run locally

Open `index.html`, or start a local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a new repository, such as `ATHENA-OS`.
2. Upload all files in this folder.
3. Open repository Settings → Pages.
4. Deploy from the main branch and root folder.
