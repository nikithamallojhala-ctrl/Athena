# Founder photo slots

Place square or near-square JPEG images at exactly:

- `assets/founders/nikitha.jpg`
- `assets/founders/shriyan.jpg`

Recommended source size: roughly 600×600 px or larger. The interface uses `object-fit: cover` inside an 84px circular frame, so do not pre-crop the file into a circle.

If either image is absent, ATHENA automatically shows the founder's initials. No remote image URL or tracker is used.
