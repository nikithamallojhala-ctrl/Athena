# ATHENA OS v2.5.0 — Signature Experience Release

This release keeps the v2.4.0 research/evidence engine intact and upgrades the human-facing experience.

## Added / restored
- Added a high-visibility **ATHENA by the Numbers** evidence stage: 27,548 athletes analyzed, 155,109 source race records, 65,895 longitudinal sequences, rolling-fold replication, empirical-domain count, evidence-integrity gates, and the athlete-level randomization scale are now intentionally prominent rather than buried in Methods.
- Enlarged founder bios and added dedicated Selected Work cards so About reads as a founder showcase, not fine print.
- Expanded founder photo filename fallbacks to include full-name and hyphen/underscore variants in common image formats.
- Restored a full equal-founder About experience with substantive bios, selected work, contact actions, and explicit 50/50 collaboration.
- Founder photo loader now accepts common JPG/JPEG/PNG/WebP and capitalization variants while preserving initials as a fallback.
- Added ATHENA System Map for fast navigation across Command, Event Lab, Intelligence, Research, Health, and Founders.
- Added active-section navigation and a page-progress rail.
- Added section numbering/domain labels for orientation.
- Added ATHENA-specific hero instrumentation, orbit labels, scanning/evidence visual language, surface spotlights, and restrained pointer parallax.
- Improved mobile access to the Getting Started guide.
- Added equal founder project links (AAINA / DataShadow) and local email contact actions without publishing full addresses as plain text.

## Research
No headline research result was changed in this visual/UX release. The evidence artifacts remain the v2.4.0 evidence-hardening outputs and are intentionally not retuned for a design pass.
