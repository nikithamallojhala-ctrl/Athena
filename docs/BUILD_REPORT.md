# Phase 1D Evidence-Hardening Build Report

ATHENA v2.4.0 is a scientific-hardening release, not a feature-bloat release. The product surface from v2.3.0 remains intact—including Pallas, the local performance log, the dynamic athlete-state engine, all Event Lab tools, Research Studio 2.0, Health/SBAR, prospective validation, founder-photo slots, and the visual redesign.

The new work focuses on evidence integrity: athlete/participant-level randomization diagnostics, subgroup calibration visibility, alternate temporal splits, a scrambled-target negative control, automated raw-data/claim verification, and an in-app claim ledger.

The most important outcome is not a higher-looking number. It is that ATHENA now makes several reviewer attacks directly testable: repeated-measure pseudo-replication, arbitrary split dependence, hidden subgroup under-coverage, target leakage, metric transcription errors, and overstatement of a small secondary cohort.
