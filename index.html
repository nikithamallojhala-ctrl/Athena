NOVELTY BOUNDARY

What ATHENA claims

Working contribution

ATHENA integrates individual baselines, temporal residual correction, an evidence gate with fallback/abstention, event context, transparent athlete tools, and a reproducible public-data evaluation layer in one local-first research platform.

Explicit boundary

ATHENA does not claim to be the first dynamic athlete-state model. It also does not claim clinical validation, guaranteed injury prevention, universal superiority, or causal effects of daily wellness inputs. PMData now provides a separate predictive validation of the wellness-state mechanism, not a medical claim.

QUANTUM INVESTIGATION

Why ATHENA does not fake “quantum AI”

Conditional closed

Relay ordering is a real assignment problem, but with four fixed athletes ATHENA can enumerate all 4! = 24 orders exactly. A quantum layer would add complexity without a measurable benefit at this scale.

The binary assignment/QUBO formulation and scaling discussion are documented in docs/QUANTUM_OPTIMIZATION_NOTE.md.

GETTING STARTED

Use ATHENA in six steps.

  1. Set your athlete profile.Choose your primary event and save a baseline resting pulse. ATHENA adapts event demand without changing the safety boundary.Go to profile →
  2. Complete today’s check-in.Use the sliders as observations, not a test you need to “pass.” If history is sparse, ATHENA shows a provisional state instead of pretending certainty.Open check-in →
  3. Read the answer first, then the why.Athlete view gives the state and session fit. Technical view exposes dimensions, personal deviations, equations, and confidence.Open Intelligence →
  4. Use Event Lab only when useful.Sprints, hurdles, pace, jumps, throws, and relay tools remain deterministic and transparent where that is the technically correct choice.Open Event Lab →
  5. Ask Pallas when you need help.Pallas works locally with no API key. It can navigate ATHENA, explain saved state history, and compare locally logged running results without inventing missing data.
  6. Inspect or run research separately.Research Mode shows public-data evidence, failures, reproducibility, N-of-1 tools, and the locked prospective-validation workflow. It does not block everyday athlete use.Open Research →
When will ATHENA say “not enough evidence”?

Only when a specific research claim or confidence-dependent prediction would be misleading. Everyday tools still work with clear provisional/fallback language.
