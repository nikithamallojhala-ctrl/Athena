# Founder photos

ATHENA looks for founder portraits in this folder.

Recommended filenames:
- `nikitha.jpg`
- `shriyan.jpg`

If your files use different names or extensions, edit `photos.json` and set the exact filename. GitHub Pages paths are case-sensitive, so `Shriyan.JPG` and `shriyan.jpg` are different files.

Square or portrait photos work best; the interface crops them into a circle automatically.
